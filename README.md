# ⬡ RecruitAI — jobs hit different when AI does the matching

> **tl;dr** — post a job, get ranked candidates. build a profile, get matched to roles. AI handles the boring part. you handle the vibe check.

---

## 🧠 what is this

an **AI-powered recruitment platform** where:
- 🏢 **HR peeps** post jobs & get applicants auto-ranked by a match score
- 🧑‍💻 **Job hunters** build slick profiles & apply in one click

no cap — your resume gets an actual AI score the second you hit submit.

---

## ✨ features that slap

| thing | what it does |
|---|---|
| 🤖 AI Match Score | rates candidates 0–100% vs job requirements |
| 🏆 Auto-Ranking | top 3 get a literal podium (🥇🥈🥉) |
| 📄 Resume Gen | one-click PDF resume from your profile |
| 📊 HR Dashboard | all apps, stats & hiring pipeline in one place |
| 🔒 Dual Roles | separate UX for HR vs candidates — no crossover |

## 🎯 how the AI score works

```
Skills match   → 40%
Education      → 30%  
Experience     → 30%
──────────────────────
70%+ = you're built different
40–69% = mid match
<40% = touch grass & update your profile
```
